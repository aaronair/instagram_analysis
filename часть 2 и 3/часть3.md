# Проекты

## 1. Background Remover Service

**GitHub:** https://github.com/aaronair/background-remover-service

### Описание

Background Remover Service — сервис для автоматического удаления фона с изображений через REST API.

Он позволяет интегрировать функцию удаления фона в сторонние приложения без использования внешних онлайн-сервисов. Проект может применяться в e-commerce, маркетплейсах, CMS и других системах, где требуется автоматическая обработка изображений товаров.

### Моя роль

Проект полностью разработан самостоятельно.

В рамках разработки я:

- спроектировала архитектуру сервиса;
- реализовала REST API;
- интегрировала модель удаления фона;
- настроила обработку изображений;
- подготовила проект к запуску в Docker.

### Технологии

- Python
- FastAPI
- Docker
- Hugging Face Transformers
- REST API
- OpenCV
- Библиотеки для обработки изображений

## 2. Local CPU Assistant

**GitHub:** https://github.com/aaronair/local_cpu_assistant

### Описание

Local CPU Assistant — локальный AI-ассистент, работающий полностью на CPU без использования облачных сервисов.

Проект позволяет запускать большие языковые модели локально, общаться с ними, выполнять различные пользовательские запросы и работать с собственными документами благодаря использованию RAG (Retrieval-Augmented Generation). Такой подход обеспечивает конфиденциальность данных, поскольку вся обработка выполняется на устройстве пользователя.

### Моя роль

Проект полностью разработан самостоятельно.

В рамках разработки я:

- спроектировала архитектуру приложения;
- интегрировала локальные LLM;
- реализовала RAG для работы с документами;
- настроила взаимодействие между компонентами системы;
- разработала пользовательский интерфейс;
- автоматизировала запуск и настройку приложения.

### Технологии

- Python
- Ollama
- Локальные LLM
- RAG (Retrieval-Augmented Generation)
- Streamlit
- Инструменты для запуска моделей на CPU
