# *Influencer Finder*

Инструмент для автоматизированного поиска блогеров для бартерного сотрудничества.

Проект анализирует существующую базу блогеров, формирует портрет идеального кандидата, находит похожие аккаунты в социальных сетях и генерирует персонализированные предложения о сотрудничестве.

> Проект выполнен в рамках тестового задания и демонстрирует подход к построению AI-агента для автоматизации influencer-маркетинга.

---

# Возможности

- Анализ существующей базы блогеров
- Построение портрета идеального кандидата
- Поиск новых релевантных блогеров
- Генерация персонализированных офферов
- Частично автоматизированный pipeline

# Pipeline

## 1. Анализ существующей базы

Инструмент подключается к bloggers.xlsx и получает список блогеров.

Для парсинга Инстаграмма использую Apify скрапер, пересобираю данные в удобный формат, нормализую их, и считаю для них дополнительные параметры.

Для каждого профиля :

- username - ник блоггера
- followers - количество подписчиков
- following - количество подписок
- posts_count - количество постов
- avg_likes	- среднее количество лайков
- avg_comments - среднее количество комментариев
- ER - коэффициент вовлеченности	
- median_ER	- медианный коэффициент вовлеченности
- video_ratio - доля reels
- photo_ratio - доля фото публикаций
- avg_caption_length - средняя длина поста/подписи
- avg_hashtags - среднее количесвто хэштегов
- ad_ratio - доля рекламных постов
- avg_mentions - количество упоминаний брендов
- posts_per_month - постов в месяц	
- posts_analyzed - проанализировано постов

Вся эта аналитика вместе с профилем и примером поста собирается в компактный .json для последующей аналитики 

Подробнее парсинг, расчет аналитик и формирование .json можно посмотреть в ноутбуке _analysis/analysis.ipynb_

Для формирования портрета идеального блогера используются следующие промты:

*Запрос №1* — найти закономерности
```
prompt = """ Ты анализируешь базу из 24 Instagram блогеров, которые уже были отобраны как подходящие для бренда.

Изучи данные и найди общие признаки.

Проанализируй:

Тематики блогеров
Общий стиль подачи
Тип аудитории
Особенности bio
Стиль написания постов
Частоту рекламы
Форматы контента
Метрики вовлеченности
Найди повторяющиеся закономерности.

Не описывай каждого блогера отдельно. Создай обобщенный портрет.

Вот данные:

{DATA} """
```

Здесь DATA - это json из предыдущего пункта
Результат работы промта можно посмотреть _analysis/анализ\_блогеров.md_ 


*Запрос №2* — создать профиль идеального кандидата
```
prompt = """ На основе анализа успешных блогеров создай портрет идеального Instagram блогера для поиска новых кандидатов.

Опиши:

Размер аудитории
Минимальный ER
Тематики
Визуальный стиль
Стиль общения
Тип контента
Как выглядит идеальная bio
Какие бренды ему подходят
Какие признаки использовать для поиска похожих аккаунтов
Формат:

Критерий
Почему важен
Как измерять
Используй анализ: {ANALYSIS} """
```

Здесь ANALYSIS - это аналитика предыдущего промта
Результат работы промта можно посмотреть _analysis/портрет\_идеального\_блогера.md_ 


## 2. Поиск новых блогеров

Так же для сбора новых блогеров используем скрапер по похожим, или поиском по нишам. Необходимо так же выгрузить профиль и посты.

Задачу ранжирования новых блогеров разделяем на два слоя:
Hard filters → фильтр по числовым параметрам/метрикам.
Semantic embedding → фильтр определяющий похожесть по эстетике, нише и подаче.

```
        Instagram data
              |
              |
              ↓
        LLM extraction
              |
              ↓
    candidate_profile.json
              |
              |
        +------------+
        |            |
        ↓            ↓
Hard filters    Semantic embedding

(метрики)      (эстетика/смысл)

            |
            ↓
       final_score
```

Итоговый score считается так:
```
final_score = (
    0.55 * metric_score +
    0.30 * embedding_similarity +
    0.15 * visual_content_score
)
```

Где metric\_score это комбинация параметров: followers, median\_ER, er\_stability\_ratio, video_ratio, posts/month, наличие ниш в bio.

Embedding\_similarity (30%) это 

```
ideal_profile_embedding
          |
          |
     cosine similarity
          |
          ↓
candidate_embedding
```

visual_content_score (15%) собирается из анализа Reels: домашняя съемка, естественный свет, лицо автора, распаковки, товары в кадре и тд.


Функцию скоринга кандидата и фильтры можно посмотреть в файле _blogger\_scoring.py_

В итоге отбираются подходящие по параметрам блогеры, и для каждого из них уже выгружен профиль и последние посты.

## 3. Генерация оффера

Для повышения персонализации каждый профиль обрабатывается LLM со следующим промтом:

```
Проанализируй профиль блогера и последние посты.

Выдели:
1. Главную тему блога.
2. Уникальную особенность подачи.
3. Какие ценности транслирует автор.
4. Почему ему подходит продукт.
5. Какую фразу можно использовать в первом предложении оффера.

Ответ в JSON.

```

Для генерации итогового предложения можно применить такой промт: 

```
Ты — менеджер по работе с инфлюенсерами бренда.

Твоя задача — написать персональное первое сообщение блогеру в Instagram Direct с предложением бартерного сотрудничества.

Твоя цель — создать ощущение, что бренд действительно изучил аккаунт автора и обращается именно к нему, а не отправляет массовую рассылку.

Входные данные:

Профиль блогера:
{{profile}}

Последние посты блогера:
{{posts}}

Анализ автора (creator_insight.json):
{{creator_insight}}

Информация о бренде:
{{brand}}

Продукт для сотрудничества:
{{product}}


Используй creator_insight.json как основной источник для персонализации:
- возьми оттуда главную тему блога;
- используй уникальную особенность подачи автора;
- опирайся на ценности и стиль коммуникации блогера;
- объясни, почему продукт подходит именно этому автору.


Правила написания сообщения:

1. Начало сообщения:

Начни с дружелюбного обращения:
"Привет, [имя]!"

Можно добавить 1 подходящий эмодзи после обращения.

Не начинай с:
❌ "Добрый день"
❌ "Уважаемый блогер"
❌ "Мы являемся представителями..."


2. Персональный первый абзац:

Первое предложение должно содержать конкретную причину, почему вы выбрали этого блогера.

Используй:
- особенности контента;
- стиль подачи;
- тематику;
- ценности автора;
- характерную рубрику или формат.

Примеры хорошей персонализации:

✅ "Нам очень нравится, как вы показываете находки для дома через простые жизненные истории — ваш формат очень близок нашей философии."

✅ "Мы заметили, как бережно вы подходите к теме ухода и делитесь честными впечатлениями о продуктах."

✅ "Нам близок ваш уютный lifestyle-формат и то, как вы превращаете обычные моменты в полезные рекомендации."

Не используй общие фразы:

❌ "Ваш блог очень интересный"
❌ "Мы давно следим за вами"
❌ "Вы крутой блогер"
❌ "Нам нравится ваш контент"

Если нет конкретного подтверждения в данных — не утверждай это.


3. Связь с продуктом:

Объясни, почему продукт подходит именно этому блогеру.

Связывай продукт с:
- тематикой автора;
- его аудиторией;
- стилем жизни;
- форматом контента.

Пример:

"Кажется, наш продукт отлично впишется в ваши обзоры находок и формат честных рекомендаций."


4. Предложение сотрудничества:

Предложи бартер мягко и естественно.

Используй формулировки:

✅ "Хотели бы предложить вам попробовать наш продукт"
✅ "Будем рады отправить вам продукт на тестирование"
✅ "Нам было бы интересно узнать ваше честное мнение"

Не используй:

❌ "Нам нужна реклама"
❌ "Сделайте рекламный пост"
❌ "Разместите интеграцию"


5. Стиль сообщения:

Сообщение должно быть:

- теплым;
- дружелюбным;
- персональным;
- похожим на настоящий Instagram Direct;
- без корпоративного языка;
- без чрезмерных комплиментов.

Используй эмодзи умеренно (1–3 максимум).


6. Длина:

- 3–5 предложений;
- до 500 символов;
- легко читается с телефона.


7. Важные ограничения:

- Не придумывай факты о блогере.
- Не упоминай информацию, которой нет в profile/posts/creator_insight.json.
- Не используй одинаковые шаблонные фразы для разных блогеров.
- Не пиши "мы изучили ваш профиль".
- Не пиши "ваша аудитория идеально подходит" — это звучит как массовая рассылка.


Верни только готовый текст сообщения для отправки в Instagram Direct.
Без анализа.
Без пояснений.
Без кавычек.

```
